# 프로그램 개요

## 무엇을 하는가

**Finance RAG Agent** 는 한국 세무 관련 질문에 답하는 프로그램입니다.

예를 들면 이런 질문을 받을 수 있습니다.

- “이월결손금은 몇 년까지 공제할 수 있어?”
- “간이과세자의 업종별 부가가치율을 알려주세요”
- “지급명세서를 늦게 제출하면 가산세가 얼마인가요?”

챗봇이 인터넷에서 아무 지식이나 끌어와 답하지 않습니다.
미리 넣어 둔 **국세청 신고안내 문서** 안에서만 찾아 답합니다.
문서에 없으면 “찾을 수 없습니다” 라고 말합니다.

인사말처럼 문서가 필요 없는 질문은 검색 없이 짧게 답합니다.

## 왜 “RAG Agent” 인가

두 가지를 합친 이름입니다.

1. **RAG** — Retrieval-Augmented Generation  
   먼저 관련 글을 **찾고(Retrieval)**, 그 글을 보고 **답을 만듭니다(Generation)**.  
   모델이 기억에만 의존하면 없는 내용을 지어낼 수 있어서, 문서부터 찾게 합니다.

2. **Agent** — 한 단계로 끝내지 않고 스스로 다음 행동을 고릅니다.  
   이 프로그램은 “검색 → 답변” 한 번이 아니라  
   **분류 → 검색 → 답변 → 검증 → (필요하면) 검색어 수정 후 재검색** 을 돕니다.

그래서 README 에서는 **Agentic RAG** 라고 부릅니다.

## 무엇을 하지 않는가

- 세무사 대신 신고서를 작성하지 않습니다.
- 최신 법령을 실시간으로 조회하지 않습니다. 넣은 문서 범위만 봅니다.
- 이전 대화를 기억하지 않습니다. 질문 한 건마다 처음부터 처리합니다.
- 상속세처럼 **넣은 문서에 없는 주제**는 지어내지 않고 거절합니다.

## 답의 재료 (데이터)

국세청에서 배포한 공개 신고안내 PDF 3건을 Markdown 으로 바꿔 사용합니다.

| 문서 | 대략적인 분량 | 다루는 주제 |
|------|----------------|-------------|
| `2025_법인세_신고안내.md` | 744페이지 분량 | 법인세 신고 |
| `2025_1기확정_부가가치세_신고안내매뉴얼.md` | 128페이지 분량 | 부가가치세 신고 |
| `원천징수의무자를위한_연말정산_신고안내.md` | 26페이지 분량 | 연말정산 |

원본 PDF 는 Git 에 넣지 않습니다. 변환된 Markdown(`data/samples/`) 만 있으면 인덱싱과 챗봇을 돌릴 수 있습니다.

이 매뉴얼은 **실무 신고 절차·사례** 를 자세히 적고, 사전처럼 “세율은 10%” 한 줄을 적지 않는 경우가 많습니다.
그래서 “어떤 경우에 / 어떻게 / 무슨 오류” 질문에 강하고, “세율이 얼마냐” 같은 한 줄 정의 질문에는 약합니다.

## 꼭 알아둘 단어

| 단어 | 쉬운 뜻 |
|------|---------|
| LLM | 글을 읽고 답하는 언어 모델. 여기서는 OpenAI `gpt-4o-mini` |
| API 키 | OpenAI 에 요청을 보낼 때 쓰는 비밀 열쇠. `.env` 의 `OPENAI_API_KEY` |
| RAG | 관련 문서를 먼저 찾고, 그 내용만 보고 답하게 하는 방식 |
| Embedding | 글을 숫자 목록(벡터)으로 바꾸는 과정. 비슷한 뜻을 비슷한 숫자로 만듭니다 |
| Vector DB | 그 숫자들을 저장해 “비슷한 글”을 빠르게 찾는 저장소. 여기서는 **ChromaDB** |
| 청크 (chunk) | 긴 문서를 검색하기 좋게 자른 조각. 이 프로젝트는 약 2,287개 |
| 인덱싱 | 청크를 벡터로 바꿔 Vector DB 에 넣는 작업. `ingest` 스크립트가 합니다 |
| LangGraph | 작업 단계를 그래프(상자 + 화살표)로 이어 실행하는 라이브러리 |
| 노드 (node) | 그래프의 한 단계. 예: 분류, 검색, 답변 생성 |
| 상태 (state) | 질문, 검색 결과, 답변처럼 단계마다 주고받는 메모장 |
| Grounded | 답이 참고 문서에 **실제로 근거**가 있다는 뜻 |
| FastAPI | 브라우저·다른 프로그램이 HTTP 로 질문할 수 있게 만드는 웹 프레임워크 |
| CLI | 터미널에서 글자로 질문하는 화면. `chat_cli.py` |

## 두 가지 사용 방법

| 방법 | 언제 쓰나 | 비밀번호 |
|------|-----------|----------|
| 터미널 챗 (`python -m src.scripts.chat_cli`) | 내 PC에서 바로 대화 | 필요 없음 |
| HTTP API (`/chat`) | 브라우저 Swagger, curl, 다른 앱에서 호출 | **필요함** (요금이 나가므로) |

API 를 인터넷/LAN 에 열어 두면 누구나 OpenAI 요금을 쓸 수 있습니다.
그래서 `/chat` 은 `.env_pwd` 의 비밀번호를 통과해야 동작합니다.
비밀번호를 비워 두면 `/chat` 은 아예 잠깁니다(HTTP 503).

## 공개 API 주소

서버를 켠 뒤 `http://localhost:8000` 기준입니다.

| 방법 | 경로 | 하는 일 |
|------|------|---------|
| GET | `/health` | 서버가 살아 있는지, 비밀번호가 설정됐는지 |
| GET | `/docs` | FastAPI 가 만들어 주는 Swagger 화면 (직접 눌러 테스트) |
| POST | `/unlock` | 비밀번호 확인 후 인증 쿠키 발급 |
| POST | `/lock` | 인증 쿠키 삭제 |
| POST | `/chat` | 질문하고 답 받기 |

`/health` 와 `/docs` 는 과금이 없어 비밀번호 없이 볼 수 있습니다.
비밀번호 값 자체는 `/health` 에도 나오지 않습니다.

| 웹 서버 | FastAPI + Uvicorn |
| 설정 | `.env`, `.env_pwd` (pydantic-settings) |
| 배포 | Docker, docker-compose |
